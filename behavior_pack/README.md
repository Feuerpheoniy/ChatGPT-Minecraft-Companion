# Behavior Pack

This folder will contain the Bedrock behavior pack.

Planned contents:
- `manifest.json` — pack metadata and UUIDs
- `entities/` — companion entity behavior definitions
- `scripts/` — optional Bedrock Script API logic, once a compatible API version is selected

The first prototype will use a custom companion entity. It will not impersonate or create a real multiplayer player.

Do not add a Script API dependency until its version has been tested against the Minecraft version installed on the Android device.
