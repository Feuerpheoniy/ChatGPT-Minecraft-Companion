# Install (prototype packs)

The files are split into Behavior Pack and Resource Pack.

- Copy `behavior_pack` into the Minecraft `behavior_packs` directory.
- Copy `resource_pack` into `resource_packs`.
- Enable both packs for the world.
- Spawn with `/summon feuer:delorean`.

On Android, the easiest delivery is two separate `.mcpack` packages. The GitHub Actions workflow in this repo can package the text files; the PNG textures in this prototype are placeholders and will be replaced with custom pixel art in a later iteration.
