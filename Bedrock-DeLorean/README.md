# DeLorean Time Machine — Bedrock Add-on (Prototype)

A first Bedrock prototype for a rideable, two-seat DeLorean DMC-12.

## Install
1. Download this folder from the repository (or the packaged release when available).
2. Put the Behavior Pack and Resource Pack in the Minecraft Bedrock packs folders, or package them separately as `.mcpack` files.
3. Activate both packs in a world.
4. In Creative, use the DeLorean spawn egg, or run:
   `/summon feuer:delorean`

## Current prototype
- Rideable entity with 2 seats
- Basic rider-controlled ground movement
- Summonable entity and spawn egg definition
- Basic geometry model
